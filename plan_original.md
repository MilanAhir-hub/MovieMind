AI Subject Project: Recommendation System

I want to build a Recommendation System using traditional Artificial Intelligence (AI) algorithms, not Machine Learning (ML).

Please help me build this project in a simple, beginner-friendly way. Do not overcomplicate it or add unnecessary features.

1. Project Objective

Build an intelligent recommendation system that recommends movies based on user preferences using traditional AI concepts such as heuristic scoring and rule-based reasoning.

2. Technology Stack

- Frontend: React.js
- Backend: Python with Flask
- AI Algorithms: Implemented in Python
- Dataset: A simple JSON or CSV file containing movie information.
- Communication: REST API between React and Flask.

3. Core Features

A. User Preferences

Allow users to select:

- Preferred movie genre
- Preferred language
- Preferred mood (action-packed, funny, emotional, etc.)
- Maximum movie duration
- Preferred rating range

B. Knowledge Base

Create a small dataset of movies containing their names, genres, languages, moods, durations, and ratings.

C. Rule-Based Reasoning

Implement simple IF-THEN rules.

Examples:

- If the user prefers action movies, increase the score of action movies.
- If a movie exceeds the user's maximum duration, exclude it.
- If the user prefers Hindi movies, prioritize Hindi movies.

D. Heuristic-Based Recommendation

Create a scoring system that evaluates how well each movie matches the user's preferences.

For example:

- Genre match: 30 points
- Language match: 20 points
- Mood match: 20 points
- Duration match: 15 points
- Rating match: 15 points

Calculate the total score out of 100 and rank the movies accordingly.

These weights can be adjusted as needed.

E. Recommendation Results

Display the top five recommended movies in the React frontend.

For each recommendation, show:

- Movie name
- Genre
- Rating
- Match score
- A short explanation of why the movie was recommended

4. AI Concepts to Demonstrate

The project should clearly demonstrate these traditional AI concepts:

1. Knowledge Representation — representing movie information in a structured dataset.
2. Rule-Based Reasoning — applying IF-THEN rules to user preferences.
3. Heuristic Evaluation — calculating scores based on preference matches.
4. Intelligent Decision-Making — ranking and selecting suitable recommendations.

Do not use machine learning models, neural networks, or AI APIs. The recommendations must be generated by our own Python algorithms.

5. How the Application Should Work

1. The user opens the React application.
2. The user selects their preferences.
3. React sends the preferences to the Python Flask backend.
4. The backend applies the rules and heuristic scoring algorithm.
5. The backend ranks the movies and selects the top five.
6. React displays the recommendations, match scores, and explanations.

6. Expected Project Structure

Frontend:

- React application
- Preference selection form
- Recommendation results page

Backend:

- Python Flask application
- Movie dataset
- Rule-based reasoning module
- Heuristic scoring and ranking module
- REST API endpoints

- Do not use machine learning or external AI APIs.
- Explain the AI algorithms clearly so I can present them to my professor.

- Provide the code in a structured manner, file by file.

Final Goal: Build a working AI-based Movie Recommendation System using React, Python Flask, rule-based reasoning, and heuristic scoring, demonstrating traditional AI concepts without machine learning.
