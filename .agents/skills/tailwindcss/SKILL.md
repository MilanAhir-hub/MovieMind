# Tailwind CSS v4 Guide

Tailwind CSS v4 is CSS-first:
- Uses `@import "tailwindcss";`
- Configures themes using `@theme { ... }` blocks directly in CSS
- Modern color syntax and responsive utility patterns
- Standalone browser runtime available via `@tailwindcss/browser@4` for zero-build environments
- High performance, clean utility classes, dark-mode native
